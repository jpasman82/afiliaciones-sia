3

Cargar el DNI

Tenés tres formas de cargar el documento. Elegí la que mejor te quede según cómo lo tengas.

Opción A · Sacar foto del DNI Recomendado
Escanear DNI: frente y dorso 👆

Te guía paso a paso: primero el frente, después el dorso. Si el código se lee, los datos se completan automáticamente.

Opción B · Subir archivo único
Subir archivo único

Si ya tenés una foto o PDF del DNI en el celu, subilo. La app abre un recortador donde ajustás el marco al frente, después al dorso.

Soporta: JPG · PNG · PDF (1 o 2 hojas)

5

Ver el estado

Cada ficha tiene una etiqueta de color que te dice en qué parte del proceso está.

El recorrido de una ficha
Cargada
Escaneada
3
En JE
4
Aprobada

Qué significa cada etiqueta:

Pendiente Recién cargada, falta procesar.
Escaneada La ficha física ya fue escaneada.
En JE Presentada ante la Junta Electoral.
Aprobada ¡Listo! Afiliación confirmada.
Con error Hay algo a corregir. Revisá el detalle.
⚠️

Si una ficha figura Con error, abrila para ver el motivo y corregí lo que indique.

🎉

¡Eso es todo!

Ya podés afiliar desde el celular. Ante cualquier duda, escribile a tu supervisor.

1

Proceso completo con foto

Principal

De principio a fin: Escanear DNI: frente y dorso. La app saca las dos fotos en orden, lee el código y completa los datos sola.

Usá esta forma cuando tengas el DNI físico al lado y puedas sacarle foto.

2

Archivo único · 1 hoja

Cuando tenés una imagen o PDF de una sola hoja con frente y dorso juntos. El recortador te deja marcar primero el frente y después el dorso.

3

Archivo único · 2 hojas

Cuando el PDF tiene 2 páginas: una con el frente y otra con el dorso. La app las separa automáticamente y vos solo recortás cada una.

4

Archivos independientes

Cuando ya tenés dos archivos separados: uno para el frente, otro para el dorso. Tocás cada slot por separado y subís cada imagen.
